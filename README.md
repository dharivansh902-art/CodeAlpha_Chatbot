
# Python Chatbot

## Project Description
This project is a simple interactive chatbot developed using Python. It can communicate with users and respond to basic messages.

## Features
- Greeting messages
- Basic conversation
- Current date and time
- Random responses
- Exit option

## Technologies Used
- Python
- Random Module
- Datetime Module

## How to Run
1. Install Python.
2. Download the project.
3. Open the project in VS Code.
4. Run the following command:

   python chatbot.py
